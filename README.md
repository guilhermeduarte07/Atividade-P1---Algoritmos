# Exercícios de Java — Estruturas Condicionais

Este repositório reúne exercícios e pequenos programas desenvolvidos em **Java** durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é praticar os fundamentos da lógica de programação, utilizando estruturas condicionais para resolver problemas simples.

## Conteúdos abordados

- Declaração de variáveis e tipos de dados
- Entrada e saída de dados
- Operadores aritméticos e relacionais
- Operadores lógicos
- Estruturas condicionais **if**, **else if** e **else**
- Tomada de decisões em programas
- Resolução de problemas básicos com Java

## Objetivo

Consolidar os conhecimentos iniciais em Java, desenvolver o raciocínio lógico e manter meus exercícios organizados no GitHub, acompanhando minha evolução na programação.

## Tecnologias utilizadas

- Java
- Visual Studio Code

## Como executar

1. Tenha o JDK instalado no computador.
2. Clone este repositório ou baixe os arquivos.
3. Abra o arquivo **.java** desejado.
4. Compile e execute o programa pelo terminal ou pela sua IDE.
